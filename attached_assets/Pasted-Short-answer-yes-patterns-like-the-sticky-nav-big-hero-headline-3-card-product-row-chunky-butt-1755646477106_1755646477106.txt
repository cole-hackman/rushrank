# Design guardrails

**Mimic:** layout, spacing scale, component types (nav → hero → 3 cards → how-it-works steps → email CTA → footer), soft radius, subtle glow/shadows, big H1, pill buttons, icon + label cards.
**Avoid:** identical copy, identical gradients, exact iconography/illustrations, 1:1 paddings/metrics.

# Make it unmistakably “RushRank”

* **Typography:** pick a single expressive display font for H1 (e.g., Space Grotesk) and a clean text font for UI.
* **Shape language:** keep generous 16–22px radii + pill buttons for consistency.
* **Motion:** tiny hover lift on cards (`translate-y-[-2px]`) and focus rings for accessibility.
* **Content voice:** frat-specific terms (PNM, bid list, IFC, rush chairs).
* **Icons:** pick one icon set and stick to it (Lucide, Phosphor).
* **Color:** choose your own brand pair (e.g., deep navy + electric lime) and apply only to accents and buttons.
