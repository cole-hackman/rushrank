Got it — let’s give RushRank a clean, modern, production-ready UI. Below is a focused overhaul plan **plus ready-to-drop React + Tailwind code** that fixes the hierarchy, spacing, contrast, and navigation issues (including the light-mode logo/heading visibility and button overlap).

# What’s wrong (from your screenshots)

* Competing visual weights; weak hierarchy (two giant CTAs + long features list).
* Inconsistent spacing → button/modal overlap on small breakpoints.
* Low contrast in light mode → brand text disappears.
* Modals aren’t clearly layered; weak focus management.
* Dashboard has “cards” but no system (sizes/spacing vary, empty states aren’t styled).

# Design goals

* **One clear primary action per screen.**
* **Solid design system** (tokens for color/spacing/typography) with **auto light/dark**.
* **Accessible** (contrast ≥ 4.5:1, keyboard focus, ARIA for dialogs).
* **Responsive** (mobile-first), no overlaps.
* **Consistent components** (Button, Card, Input, Modal, EmptyState, Header).

# 2) Core layout + components

**`AppShell.tsx`**

```tsx
import { useEffect, useState } from 'react';

export default function AppShell({ children }: { children: React.ReactNode }) {
  const [theme, setTheme] = useState<'light'|'dark'>(
    window.matchMedia && window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light'
  );

  useEffect(() => {
    document.documentElement.setAttribute('data-theme', theme);
  }, [theme]);

  return (
    <div className="min-h-screen">
      <header className="sticky top-0 z-40 border-b bg-[var(--surface)]/95 backdrop-blur">
        <div className="mx-auto flex max-w-6xl items-center justify-between px-4 py-3">
          <div className="flex items-center gap-2">
            <span className="inline-flex h-9 w-9 items-center justify-center rounded-lg bg-brand-500 text-white font-semibold">RR</span>
            <div className="leading-tight">
              <div className="text-lg font-semibold text-[var(--text)]">RushRank</div>
              <div className="text-xs text-[var(--text-muted)]">Digital Rush Voting Platform</div>
            </div>
          </div>
          <div className="flex items-center gap-2">
            <button
              onClick={() => setTheme(t => t === 'dark' ? 'light' : 'dark')}
              className="inline-flex items-center rounded-lg border px-3 py-2 text-sm hover:bg-black/5 dark:hover:bg-white/5"
              aria-label="Toggle theme"
            >
              <span className="hidden sm:inline">{theme === 'dark' ? 'Light' : 'Dark'} mode</span>
              <span className="sm:hidden">{theme === 'dark' ? '☀️' : '🌙'}</span>
            </button>
            <div className="h-8 w-8 rounded-full bg-brand-100 text-brand-700 grid place-items-center font-medium">CO</div>
          </div>
        </div>
      </header>
      <main className="mx-auto max-w-6xl px-4 py-8">{children}</main>
    </div>
  );
}
```

**Buttons / Cards / Inputs (utility components)**

```tsx
export function Button({variant='primary', className='', ...props}: any) {
  const base = "inline-flex items-center justify-center rounded-lg px-4 py-2.5 text-sm font-medium focus:outline-none focus-visible:ring-2 focus-visible:ring-ring/80 disabled:opacity-50 disabled:cursor-not-allowed";
  const map:any = {
    primary: "bg-brand-500 text-white hover:bg-brand-600",
    secondary: "border hover:bg-black/5 dark:hover:bg-white/5",
    ghost: "hover:bg-black/5 dark:hover:bg-white/5",
  };
  return <button className={`${base} ${map[variant]} ${className}`} {...props} />;
}

export function Card({title, subtitle, children, action}: any) {
  return (
    <section className="rounded-xl border bg-[var(--surface)] shadow-card">
      <div className="flex items-center justify-between gap-3 border-b px-5 py-4">
        <div>
          <h3 className="font-semibold">{title}</h3>
          {subtitle && <p className="text-sm text-[var(--text-muted)]">{subtitle}</p>}
        </div>
        {action}
      </div>
      <div className="p-5">{children}</div>
    </section>
  );
}

export function TextInput(props: React.InputHTMLAttributes<HTMLInputElement>) {
  return (
    <input
      className="w-full rounded-lg border px-3 py-2 text-sm focus:outline-none focus:ring-2 focus:ring-ring/70"
      {...props}
    />
  );
}
```

**Accessible Modal (prevents overlap & manages focus)**

```tsx
import { useEffect, useRef } from 'react';
export function Modal({open, onClose, title, children}: any) {
  const ref = useRef<HTMLDivElement>(null);
  useEffect(() => {
    if (open) ref.current?.querySelector<HTMLElement>('[data-autofocus]')?.focus();
  }, [open]);
  if (!open) return null;
  return (
    <div className="fixed inset-0 z-50">
      <div
        className="absolute inset-0 bg-black/50 backdrop-blur-sm"
        aria-hidden
        onClick={onClose}
      />
      <div role="dialog" aria-modal="true" aria-label={title}
        className="absolute inset-0 grid place-items-center p-4">
        <div ref={ref} className="w-full max-w-md rounded-2xl border bg-[var(--surface)] shadow-modal">
          <div className="flex items-center justify-between border-b px-5 py-4">
            <h2 className="text-base font-semibold">{title}</h2>
            <button className="p-1 rounded-md hover:bg-black/5 dark:hover:bg-white/5" onClick={onClose} aria-label="Close">✕</button>
          </div>
          <div className="p-5">{children}</div>
        </div>
      </div>
    </div>
  );
}
```

# 3) Welcome screen (single primary CTA; no overlap)

**`Welcome.tsx`**

```tsx
import { useState } from 'react';
import AppShell from './AppShell';
import { Button, Card, TextInput } from './ui';
import { Modal } from './Modal';

export default function Welcome() {
  const [joinOpen, setJoinOpen] = useState(false);
  const [code, setCode] = useState('');

  return (
    <AppShell>
      <div className="grid gap-8 md:grid-cols-[1.2fr_.8fr]">
        <Card
          title="Welcome to RushRank"
          subtitle="Streamline your fraternity rush process with real-time voting and analytics."
          action={<Button onClick={() => setJoinOpen(true)}>Join a Voting Round</Button>}
        >
          <ul className="mt-2 space-y-2 text-sm text-[var(--text-muted)]">
            <li>• Real-time swipe voting interface</li>
            <li>• Comprehensive PNM profiles with photos</li>
            <li>• Advanced filtering & analytics</li>
            <li>• Export results securely</li>
          </ul>
        </Card>

        <Card
          title="Admin Dashboard"
          subtitle="Manage PNMs, start rounds, and view results."
          action={<Button variant="secondary">Open Dashboard</Button>}
        >
          <p className="text-sm text-[var(--text-muted)]">
            For rush chairs and admins only.
          </p>
        </Card>
      </div>

      <Modal open={joinOpen} onClose={() => setJoinOpen(false)} title="Join Voting Round">
        <form className="space-y-4" onSubmit={(e)=>{e.preventDefault(); /* navigate */}}>
          <label className="text-sm font-medium">Room Code</label>
          <TextInput
            data-autofocus
            inputMode="text"
            placeholder="e.g., ABC123"
            value={code}
            onChange={(e)=>setCode(e.target.value.toUpperCase())}
            aria-describedby="join-help"
          />
          <p id="join-help" className="text-xs text-[var(--text-muted)]">Enter the code shared by your rush chair.</p>
          <div className="flex items-center justify-end gap-2 pt-2">
            <Button variant="secondary" type="button" onClick={()=>setJoinOpen(false)}>Cancel</Button>
            <Button type="submit">Join Round</Button>
          </div>
        </form>
      </Modal>
    </AppShell>
  );
}
```

**Why this fixes your issues**

* Clear hierarchy (one primary CTA per card).
* Proper modal overlay + centered dialog prevents overlap.
* Brand and subtitle are readable in **light mode** and **dark mode**.
* Spacing is consistent; cards never collide at mobile widths.

# 5) UX guidelines baked into this redesign

* **Contrast & visibility**: text/brand color tokens ensure legibility in both themes.
* **Keyboard support**: focus rings, close modal with Esc (you can add a keydown listener if desired).
* **Responsive**: grid stacks on mobile; no absolute-positioned CTAs = no overlapping.
* **Clear navigation**: Welcome has two cards (Join vs Admin). Dashboard groups data (metrics → quick actions → table).
* **Empty states** guide users instead of leaving “No PNMs found”.
