# 📘 RushRank Product Design Document

**Version:** v1.0
**Prepared For:** Replit AI agent + RushRank team
**Date:** 2025-08-19

---

## 🎯 Vision

RushRank is the **chapter-first platform** that helps fraternities manage **rush attendance, PNM tracking, and voting** seamlessly. It should feel **clean, modern, and unified** across:

* **Marketing** (landing page, onboarding)
* **Chapter Operations** (dashboard, events, PNMs)
* **Decision-Making** (live voting, analytics, reports)

The product should balance **fraternity culture (casual, fun, high-energy)** with **serious utility (accuracy, transparency, accountability).**

---

## 🖼 Brand & Design Language

### Typography

* **Display / Headings:** Space Grotesk (bold, geometric, energetic)
* **Body / UI:** Inter (clean, highly legible, pairs well with Grotesk)

### Color Tokens

* `--rr-bg`: Deep Navy (`hsl(220, 40%, 7%)`)
* `--rr-surface`: Slightly lighter navy (`hsl(220, 30%, 12%)`)
* `--rr-accent`: Electric Lime (`hsl(100, 85%, 55%)`) — for CTA buttons, highlights
* `--rr-secondary`: Soft Purple (`hsl(270, 70%, 60%)`) — accent alt
* `--rr-muted`: Neutral Gray (`hsl(0, 0%, 70%)`) — labels, dividers
* `--rr-card`: White/5% surface overlay

### Shape Language

* Rounded corners (12–20px depending on container)
* Pill-shaped buttons
* Cards with **glass-like surfaces** (low-opacity backgrounds + border)

### Motion

* **Framer Motion** micro-interactions (hover lifts, fade-in, tab transitions)
* Smooth **page transitions** (opacity + slight slide)
* Voting actions should have **instant visual feedback**

### Mobile

## 📱 Screens & Components

### 1. Landing Page (Marketing Site)

**Goal:** Convert interest into signups

* Hero: Big headline “Rush week, without the chaos” + 2 CTAs (Create Chapter / See Demo)
* 3-Card Row: Attendance / Voting / Analytics
* How It Works (4 steps)
* Testimonials / Logos (optional later)
* Email CTA (early access)
* Footer

---

### 2. Onboarding (First Chapter Setup)

* Step 1: Create Chapter → set chapter name, school, logo
* Step 2: Invite Exec → email invites (Supabase auth magic links)
* Step 3: Import PNMs → CSV or manual entry
* Step 4: First Event Setup

---

### 3. Dashboard

**Top-Level Metrics:**

* Today’s event (if active)
* Total PNMs
* Open votes
* Attendance % trend

**Cards / Layout:**

* **Event List**: QR-enabled check-in, status indicators
* **PNM Table**: profile photos, attendance history, ratings
* **Voting Panel**: active or scheduled sessions
* **Analytics Widget**: funnels, member activity

---

### 4. Events (Attendance)

* Event Card: Title, Date, Status (Upcoming, Live, Completed)
* Check-in: QR scan, manual override
* Attendee List with timestamps
* Notes section

---

### 5. PNMs

* PNM Profile: photo, name, contact, notes
* Attendance Timeline (event badges)
* Ratings from members
* Vote history

---

### 6. Voting

* Voting Session: Live progress (real-time WS updates)
* Options: Yes / No / Custom scale (e.g., 1–5)
* Anonymity toggle (blind vs open voting)
* Results screen: bar chart + breakdown

---

### 7. Analytics

* Event Funnel (attended → bid → accept)
* Heatmap of attendance
* Member participation chart
* Export to CSV/PDF

---

### 8. Settings

* Chapter Profile (logo, name, school)
* Role Management (admin, exec, member)
* Integrations (Google Drive export, notifications)

## 🛠 Component System (shadcn/ui + Tailwind)

* `Navbar` (sticky, pill CTAs, dropdown for profile)
* `HeroSection` (big text + CTA)
* `FeatureCard` (icon, title, points, CTA)
* `StepList` (numbered onboarding / how it works)
* `DashboardCard` (metric widget w/ icon + trend)
* `DataTable` (PNMs / Events / Votes) with filters
* `Modal` (vote session, add PNM, etc.)
* `Toast` (Framer Motion pop-ins for feedback)
* `Chart` (TanStack + D3 wrappers for analytics)

---

## 🔒 Security & Data Integrity

* Supabase Auth + JWT (Python-JOSE)
* RLS: every query scoped to `chapter_id`
* Audit Logs: log every vote, attendance mark, or role change
* Encrypted file uploads (GCS) for PNM photos

---

## 🌐 Offline & Realtime

* PWA offline mode:

  * Cache dashboard + PNM list locally
  * Offline check-ins queued → sync on reconnect
* WebSocket voting sessions (FastAPI WS)
* Optimistic UI (TanStack Query + React state sync)

---

## 📊 Analytics & Admin Tools

* Admin Dashboard: adoption metrics (# of chapters, PNMs tracked)
* Error monitoring (Sentry / Replit observability)
* Usage reports for resume / portfolio
