Backend Language

Go all‑in on FastAPI and retire Express. It’s early—keeping two servers adds complexity with no real benefit.

Migration Strategy

Full replacement (greenfield). Stand up FastAPI with Supabase auth + the new schema, then point the frontend to the new API base URL. No side‑by‑side.

Authentication Priority

Start with Email Magic Link / OTP only. It’s frictionless and fastest to ship. Add Google OAuth later (nice‑to‑have, not MVP‑critical).

Chapter Management

Bootstrap via seed + invite flow:

Create a single system admin (your email) via a seed SQL script.

That system admin creates a Chapter and designates the first Chapter Admin (by email).

Chapter Admin invites members by email (or enables a domain allowlist like @university.edu).

Roles: admin | member | observer. Only admins can create rounds, import PNMs, export data.

This keeps control tight and avoids accidental open signups.

Data Migration

If your existing data is toy/demo, start fresh with the new schema (faster, cleaner).

If you have meaningful test or pilot data, write a one‑off migration script:

Export old PNMs/votes → map to new tables (chapters, pnms, rounds, votes, notes).

Generate missing foreign keys (e.g., set chapter_id for PNMs from your default chapter).

Validate referential integrity, then import.
