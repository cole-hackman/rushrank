✅ Feature: PNM Attendance Tracking

🧩 Core Functionality

1. Event Creation
	•	Admins or rush chairs create events with:
	•	Name (e.g. “House Tour”, “Game Night”)
	•	Time & date
	•	Optional notes (e.g. dress code, location)
	•	Type (mandatory, optional, invite-only)

2. Attendance Check-In

Options:
	•	Manual: An officer taps “Check In” next to each PNM’s name at the event.
	•	QR Code: Generate a QR for the event; PNMs scan it to mark themselves present.
	•	Room Code / PIN: PNMs enter a unique code (like “RUSH2025”) during a specific time window.
	•	Geo-location (Advanced): Use location verification to confirm they showed up (only if you’re building a mobile app later).

3. Attendance Log
	•	Each PNM gets a timeline showing which events they attended
	•	Admins can sort/filter by:
	•	PNMs with perfect attendance
	•	PNMs who missed required events
	•	PNMs who ghosted after Day 1

⸻

📊 How It Could Look in UI

📅 New Tab or Section: “Events”
	•	List of upcoming & past events
	•	Button: “+ Add New Event”

👥 PNM Profile View
	•	Attendance section below their tags (e.g. ✔ 3/5 events attended)
	•	Colored dots: ✅ Green = attended, ❌ Red = missed, 🟡 Gray = not invited

📋 Admin Attendance Dashboard
	•	Table view: Rows = PNMs, Columns = Events
	•	Export as CSV or Google Sheet
	•	Attendance % automatically calculated

⸻

✍️ Extra Ideas
	•	Reward PNMs with high attendance (e.g. special shoutouts, auto-favorite)
	•	Flag PNMs who missed >50% of invite-only events
	•	Allow notes per event (e.g. “showed up late but good convo with Alex”)
	•	Option for anonymous notes by voters per event
